OpenPedCanExpress Expression Plots Docs Release notes

Documentation

OpenPedCanExpress is a browser-based tool for exploring gene expression in pediatric tumors compared with normal tissue controls. Search a gene, compare its expression across tumor histologies and normal samples, and export publication-ready plots.

Quick start

  1. Type a gene symbol (for example EGFR, TP53, or CD276) and press Enter.
  2. The plot shows expression for each tumor and normal group, with one box per group.
  3. Use Configure Groups to choose which cohorts, histologies, molecular subtypes, and normal tissues to show.
  4. Optional: adjust Font size and Height (they change the plot on screen and in exports), and optionally set the Export box width and file type (PDF, JPG, PNG, or SVG).
  5. Use Export Plot to save the figure.

The first load takes a few seconds while the database engine starts. After that, each gene search only downloads the rows for that gene.

Reading the plot

  • Facets. Groups are arranged in facets: tumor cohorts first (PBTA, TARGET, GMKF), then normal controls (Pediatric Brain, Evo-devo, GTEx <40). Facet widths are proportional to the number of groups.
  • Boxes. Each box spans the first to third quartile with a line at the median. Whiskers extend to the most extreme values within 1.5 × the interquartile range of the box.
  • Points. Every sample is drawn as a point, jittered horizontally so overlapping samples stay visible. Hover over a point to see its sample ID, group, molecular subtype (for tumors), and value.
  • Y-axis. By default, values are log2(TPM + 1). Use the Scale menu to switch to log10(TPM + 1) or raw TPM. The y-axis is shared across all facets so groups can be compared directly.
  • Sorting. Tumor groups can be sorted alphabetically or by median expression (high to low, or low to high). GTEx tissues are alphabetical. Evo-devo groups follow Order Evo-devo by (developmental time, then tissue, by default).

Many groups, small screens. The plot fills the window. When there are too many groups to keep the rotated labels readable, it widens instead and scrolls sideways; lower Font size to fit more in the window, or raise it to make the text larger. The plot is redrawn when the window is resized or you zoom the browser (Cmd/Ctrl and +/-).

Configuring sample groups

Open Configure Groups to choose what is plotted.

  • Cohorts. All cohorts (PBTA, TARGET, and GMKF) are shown by default, each in its own facet. Uncheck a cohort to hide it.
  • Histologies. Tumor groups, listed under their cohort heading.
  • Molecular subtypes. Select subtypes to plot those samples separately. Split by molecular subtype divides every tumor group by subtype.
  • Control cohorts. Choose GTEx, Evo-devo, and pediatric normal brain groups. By default the plot shows all GTEx tissues, pediatric brain, and evo-devo prenatal and postnatal boxes for all seven tissues.
    • Group Evo-devo by: Prenatal / Postnatal for each tissue (default), Exact timepoint, or Tissue only (one box per tissue). See Control groups.
    • Group GTEx by: Group (whole tissues, default) or Subgroup (for example Brain - Cerebellum).
    • Order Evo-devo by: Time, then tissue (default; all prenatal boxes, then all postnatal) or Tissue, then time (each tissue's timepoints together).
    • Select many groups at once with the tissue category checkboxes (such as Reproductive Organs or Skin/Fat), the All <tissue> checkboxes, and, for evo-devo exact timepoints, the prenatal only and postnatal only checkboxes.

Top facet labels controls the cohort labels above the plot (PBTA, TARGET, ...). Auto puts a multi-word label on two lines when it is too wide for its facet (for example Pediatric over Brain) and rotates it only when it still does not fit, for example a cohort with one group; you can also force horizontal or rotated labels, or hide them.

Show sample count (N) in axis labels (on by default) adds each group's number of samples to its label, for example Forebrain-Prenatal (N=32). The counts update with your selections, including when you split by molecular subtype, and appear in exported plots.

Click Apply to update the plot.

Exporting plots

Choose a format (PDF, JPG, PNG, or SVG; raster images are 300 DPI) and click Export Plot. By default the export has the same size, proportions and font size as the plot on screen, so what you see is what you get. You can change:

  • Font size and Height: these also change the plot on screen. Margins scale with the font size so labels are not clipped.
  • Export box width: leave blank (auto) to match the screen, or enter the pixels per group to set the figure width yourself, for example to compress a plot with many groups.

The underlying data

Expression values are RSEM TPM, collapsed to gene symbol, from the OpenPedCan project (OpenPedCan v15 data release). All data, tumor and control, was harmonized with the Gabriella Miller Kids First RNA-Seq workflow using the GENCODE v39 reference, so expression values are comparable across cohorts. A preprocessing script (scripts/01-build-expression-parquet.R) converts them into Parquet files split by the first letter of the gene symbol (A–H, I–P, Q–Z). The app queries these files in the browser with DuckDB-WASM, so there is no server or database.

Tumor samples

  • RNA-Seq tumor samples from the PBTA, TARGET, and GMKF cohorts.
  • Only independent primary specimens are used (one per participant within each cohort), from the OpenPedCan independent specimens list for each cohort.
  • PBTA neuroblastoma specimens are excluded.
  • Neuroblastoma MYCN subtypes come from the OpenPedCan-Project subtyping branch (rokita/subtyping-integrate).

The same control cohorts are used in TAPESTRY.

Plot groups

  • PBTA. Histology groups and molecular subtypes come from TAPESTRY, so colors, groups and subtypes match across Rokita Lab tools.
  • TARGET and GMKF. Samples are grouped by OpenPedCan cancer_group. Groups with 3 or fewer samples are not shown, and Ganglioneuroblastoma is combined with Neuroblastoma. The mapping is in plot-groups.tsv.

Control groups

  • GTEx. The group is the tissue (30 groups, for example Brain or Adipose); the subgroup is the specific site (53 subgroups, for example Brain - Cerebellum or Adipose - Subcutaneous).
  • Evo-devo. Labels are <tissue>-<timepoint>, for example Forebrain-4 Weeks Post Conception or Heart-Neonate. The prenatal/postnatal grouping combines all post-conception weeks (4-19) into <tissue>-Prenatal and Neonate through Elderly into <tissue>-Postnatal. Tissue only puts every timepoint of a tissue in one box.
  • Tissue categories (used by the category checkboxes): Brain & Nerve (Brain, Nerve, Forebrain, Hindbrain), Reproductive Organs (Ovary, Testis, Uterus, Vagina, Prostate, Fallopian Tube, Cervix), Skin/Fat (Skin, Adipose), Heart & Blood (Heart, Blood and arteries, Spleen), Digestive (Colon, Esophagus, Small Intestine, Stomach, Liver, Pancreas, Minor Salivary Gland), Kidney & Bladder, Endocrine (Adrenal Gland, Thyroid, Pituitary), Lung, Muscle, Breast, and Cell Lines (cultured fibroblasts and EBV-transformed lymphocytes).
